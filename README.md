# Portfolio · Emiliano Martínez

Sitio personal de Emiliano Martínez, Full Stack Developer (Caleta Olivia, Argentina).

Hecho con React + Vite + TypeScript, sin backend.

## Desarrollo

```bash
npm install
npm run dev      # servidor local
npm run build    # build de producción en dist/
npm run preview  # sirve el build
```

El contenido (proyectos, experiencia, habilidades) está en `src/data.ts`.

## Deploy

En Vercel: importar el repo, framework **Vite**, comando `npm run build`, carpeta de salida `dist`.
